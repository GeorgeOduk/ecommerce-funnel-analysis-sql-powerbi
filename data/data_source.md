# Data Source

This project uses a public e-commerce funnel dataset containing five CSV files:

- user_table.csv
- home_page_table.csv
- search_page_table.csv
- payment_page_table.csv
- payment_confirmation_table.csv

These files represent a user journey through the funnel:

Home Page - Search Page - Payment Page - Purchase Confirmation

The data was used for educational and portfolio purposes.
