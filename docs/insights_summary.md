# Insights Summary

## Overall Funnel Performance

The funnel shows a steep decline from Home Page to Purchase Confirmation.

| Stage | Users |
|---|---:|
| Home Page | 90,400 |
| Search Page | 45,200 |
| Payment Stage | 6,030 |
| Purchase Confirmation | 452 |

Only 452 users completed the full funnel, representing an overall conversion rate of 0.50%.

## March 2015 Diagnostic Finding

Performance deteriorates sharply from March 2015 onward.

Key changes:

- Mobile Home - Search fell from approximately 80% to 20%.
- Desktop Search - Payment fell from approximately 15.91% to 4.00%.

This suggests a likely product, UX, tracking, or technical issue beginning around March 2015.
