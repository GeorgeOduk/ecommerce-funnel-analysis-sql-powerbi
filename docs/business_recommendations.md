# Business Recommendations

## 1. Investigate March 2015 Changes

The strongest diagnostic finding is the sharp deterioration from March 2015 onward.

Recommended checks:

- product release logs
- website UX changes
- tracking implementation changes
- mobile page rendering issues
- search functionality changes
- checkout/payment errors
- page speed or performance changes

---

## 2. Improve Search - Payment Progression

The business loses 39,170 users after Search.

Possible actions:

- improve product search relevance
- simplify navigation from search results to product pages
- make product calls-to-action "(CTAs)" clearer
- reduce unnecessary steps before payment
- improve product page trust signals
- personalise recommendations

---

## 3. Reduce Payment - Purchase Friction

Only 7.50% of Payment users complete purchase.

Possible causes:

- hidden shipping costs
- payment errors
- mandatory account creation
- lack of trust signals
- long forms
- limited payment methods

Recommended actions:

- simplify checkout forms
- show costs earlier
- add trust badges
- offer guest checkout
- test alternative payment methods
- monitor payment error logs
